Autonomous UAV for Crop Phenotyping in GPS-Denied Environments

ROS 2 C++ FAST-LIVO2 Pixhawk 6C

The Challenge: Standard GPS drones fail in dense crop canopies due to signal multipath and lack of geometric features for visual SLAM.

The Solution: Architected a custom 500mm carbon-fiber quadcopter with an onboard Odroid N2+. Implemented FAST-LIVO2 (LiDAR-Inertial Odometry) to achieve drift-free state estimation (< 2% over 500m) without GPS. Integrated ArduPilot EKF3 for sensor fusion.

🤖 Research & Engineering

Safe Multi-Agent RL for Cooperative Navigation

PyTorch SAC MPC

Developed a safe MARL framework combining Soft Actor-Critic (SAC) with a centralized attention mechanism. Integrated a hybrid Model Predictive Control (MPC) safety shield to enforce hard collision constraints. Achieved 80.5% success rates in complex obstacle environments.

Stochastic Multi-Robot Task Allocation (SCOBA)

Python PM-CBS EKF

Designed a unified warehouse coordination system combining Stochastic Utility-Based Allocation with Priority-Based Conflict-Based Search (PM-CBS). Implemented EKF localization and topometric graph planning to generate collision-free, time-consistent trajectories.

Visual-to-Motion Robotic Sketching Arm

Python MoveIt OpenCV

Developed a perception-action pipeline using OpenCV for contour extraction and Inverse Kinematics (IK) solvers in MoveIt. Performed extrinsic calibration with a RealSense D455 to enable dynamic sketching.

Bayesian Deep Learning for Uncertainty

PyTorch ResNet TensorFlow.js

Built a dual-head ResNet model for simultaneous age and gender classification. Implemented Monte Carlo Dropout to quantify predictive uncertainty, allowing the system to flag "low-confidence" predictions in real-time.
