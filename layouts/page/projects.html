Safe Multi-Agent RL for Navigation

PyTorch SAC MPC Attention

Developed a custom Python simulation (replacing ROS/Gazebo) to train a decentralized Soft Actor-Critic (SAC) model with a centralized attention critic. Integrated a hybrid MPC safety shield to guarantee constraint satisfaction, achieving 80.5% success rates in obstacle-dense environments.

Stochastic Multi-Robot Task Allocation

Python PM-CBS EKF Topometric Maps

Designed a warehouse coordination system combining SCOBA (Stochastic Utility Allocation) with Priority-Based Conflict-Based Search (PM-CBS) on topometric region graphs. Implemented EKF localization to ensure zero collisions and high utility efficiency compared to greedy baselines.

Visual-to-Motion Robotic Sketching

ROS MoveIt OpenCV Interbotix

Built a real-world vision-guided drawing system for the Interbotix WidowX 250s. Implemented a visual feedback loop using an Intel RealSense D455 to evaluate stroke accuracy and text placement in real-time. Validated in RViz before physical deployment.

Real-Time Age & Gender Prediction

TensorFlow.js ResNet-152 Bayesian DL

Deployed a dual-head ResNet-152 model for simultaneous age/gender prediction. Implemented Monte Carlo Dropout to quantify predictive uncertainty and exported models to TensorFlow.js for low-latency client-side inference (MAE: 5.17 years).
